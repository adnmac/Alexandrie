# Glossaire d'Alexandrie

Un seul nom par chose, partout : boutons, menus, titres, bulles d'aide, messages.
L'interface est en français ; menus et boutons suivent la casse d'Apple en français
(majuscule au premier mot seulement : « Mettre à la corbeille »).

## Choses

| Terme | Sens | Pas |
| --- | --- | --- |
| Bibliothèque | Tous les livres connus d'Alexandrie : le dossier de livres plus les imports | collection, catalogue |
| Dossier de livres | Le dossier choisi par la personne ; lu, jamais modifié | source, racine |
| Livre | Une œuvre, avec un ou plusieurs fichiers (formats) | titre, ouvrage, élément |
| Fichier | Un exemplaire d'un livre dans un format | copie (sauf pour les doublons masqués) |
| Format | EPUB, MOBI, AZW3, AZW, PDF | type, extension |
| Fiche | La colonne de droite : couverture, actions et informations du livre sélectionné | détail, inspecteur |
| Informations | Titre, auteurs, éditeur, série, genre, date, ISBN, langue, résumé | métadonnées (sauf dans l'aide technique) |
| Kindle | L'appareil branché, tel que le Mac le voit | liseuse (pour l'appareil branché), lecteur |
| Liseuse | Une Kindle connue, avec son nom et son étagère, branchée ou non | appareil, device |
| Étagère | Les livres qu'une liseuse doit avoir | collection, liste de lecture |
| En attente d'envoi | Livres qui partiront à la prochaine connexion de la Kindle | file, queue |
| Corbeille | Livres retirés de la bibliothèque, restaurables | supprimés, poubelle |
| Notes et surlignages | Ce que la personne a noté ou surligné sur la Kindle | annotations, clippings |
| Proposition | Une différence trouvée par la vérification en ligne, à appliquer ou ignorer | suggestion, correction (pour ce qui n'est pas appliqué) |
| Doublons | Fichiers du même livre dans le même format ; un seul est affiché | copies |
| Réglages | La fenêtre ⌘, | Préférences, Paramètres |

## Actions

| Terme | Sens | Pas |
| --- | --- | --- |
| Importer des livres… | Copier des fichiers dans la bibliothèque (⌘O ou glisser sur la fenêtre) | ajouter, ouvrir |
| Envoyer à la Kindle | Copier le livre (converti si besoin) sur la Kindle branchée | transférer, charger, synchroniser |
| Envoyer à la connexion | Mettre le livre en attente d'envoi quand aucune Kindle n'est branchée | programmer, plus tard |
| Ajouter à l'étagère / Retirer de l'étagère | Changer ce qu'une liseuse doit avoir | épingler |
| Retirer de la Kindle… | Effacer des fichiers de l'appareil (confirmé) | supprimer de la Kindle |
| Éjecter la Kindle | Démonter l'appareil avant de le débrancher | déconnecter |
| Mettre à la corbeille | Retirer un livre de la bibliothèque, restaurable | supprimer |
| Restaurer | Remettre un livre de la corbeille dans la bibliothèque | récupérer |
| Supprimer définitivement… | Effacer un livre importé ; ne revient pas | vider |
| Vérifier en ligne | Comparer les informations à la BnF puis à Open Library | synchroniser, mettre à jour |
| Appliquer / Ignorer | Accepter ou écarter une proposition | valider, rejeter |
| Exporter en EPUB… | Écrire un EPUB à partir d'un MOBI ou AZW3 | convertir |
| Afficher dans le Finder | Montrer le fichier dans le Finder | révéler |
| Coup d'œil | Aperçu du fichier sans l'ouvrir (Espace) | aperçu rapide, Quick Look |
| Annuler | ⌘Z, défait la dernière action nommée | défaire |
